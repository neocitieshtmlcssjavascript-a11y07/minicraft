# 🎮 Мини-Майнкрафт 2D (Pygame Project)Простая двухмерная игра-песочница в стиле Minecraft, написанная на языке Python с использованием библиотеки Pygame. Проект разбит на модули для удобства чтения и масштабирования.# 🛠️ ФункционалГенерация мира: Автоматическое создание слоев травы, земли и камня.Управление персонажем: Движение игрока влево и вправо по поверхности.Модульная система подсказок: Встроенное всплывающее меню помощи.# 📂 Структура проектаgame.py — Главный исполняемый файл игры (игровой цикл, физика, отрисовка мира и игрока).help.py — Вспомогательный модуль для отрисовки графического интерфейса справки (UI).README.md — Описание проекта и инструкция по запуску.# 🚀 Запуск проекта1. ТребованияДля работы игры необходим установленный Python 3.x и cpp библиотека Pygame.2. Установка зависимостейОткрой терминал в папке проекта и установи Pygame:bashpip install pygame
Используйте код с осторожностью.3. Старт игрыЗапусти главный файл проекта через командную строку:bashpython game.py
Используйте код с осторожностью. # 🕹️ УправлениеСтрелка Влево — Переместить персонажа влево.Стрелка Вправо — Переместить персонажа вправо.H (удержание) — Показать всплывающее окно со справкой по игре.
